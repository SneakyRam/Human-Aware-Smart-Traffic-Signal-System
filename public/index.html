How SAHTCS Works

A 4-step intelligent decision loop running every signal cycle.

1️⃣

Sense

Detects vehicle density, pedestrian count, emergency vehicles, and waiting time from all four directions simultaneously.

2️⃣

Analyze

Multi-factor priority algorithm scores each direction considering density, urgency, fairness, starvation, and emergency status.

3️⃣

Decide

AI selects the optimal signal phase with adaptive cycle timing, enhanced by RL modifiers and predictive adjustments.

4️⃣

Learn

Q-Learning updates weights based on outcomes, continuously improving future decisions. The system gets smarter over time.
